# Glossary

- **Canonical identity** — stable provider-qualified identifier used for routes, ownership, and caches.
- **Display episode** — number shown to the user within the selected season/title.
- **Playback episode** — number or ID expected by the streaming provider.
- **Mapping segment** — verified relationship translating episodes between content/provider models.
- **Season chain** — ordered AniList-related anime entries representing sequels/cours/parts.
- **Local source** — TypeScript provider adapter running inside a native Capacitor client.
- **Local media proxy** — on-device HTTP bridge used for protected, rewritten, or offline media.
- **Readable/playable availability** — whether a metadata record has a working content provider.
- **Persistent player** — player state that survives frontend route navigation.
- **Vault** — Yorumi's hidden product interface and separate library state; not this Obsidian knowledge vault.
- **Yumi** — recommendation/chat feature backed by the backend chat endpoint.

# Yorumi Knowledge Vault

This directory is the durable repository memory for humans and coding agents. Open `obsidian/` as an Obsidian vault and begin at [[00 - Repository Index]].

## Rules

- Source code remains authoritative; notes explain where behavior lives and how parts connect.
- Keep notes concise, linked, and repository-specific.
- Update the relevant map when architecture, data flow, build steps, routes, caches, or invariants change.
- Put durable decisions in `decisions/`; use the templates when useful.
- Never store API keys, signing data, tokens, user data, or other secrets here.
- `.obsidian/` is intentionally ignored so each contributor can keep personal Obsidian settings.

## Agent Reading Order

1. [[00 - Repository Index]]
2. [[01 - Quick Start]]
3. The map for the layer being changed
4. [[reference/Invariants and Guardrails]]
